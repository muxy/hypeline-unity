# Muxy Hypeline Unity walkthrough

The current installation, prefab, code-only, and live viewer-action instructions
are in the [Hypeline Unity developer guide](https://muxy.github.io/gateway-unity/).

Use that guide with the SDK version installed in your project. The older MEDKit
and MuxyGameLink walkthrough has been retired; its package and WebSocket setup
do not describe this Hypeline package.
